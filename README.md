# Grand Token Auto: 四九城

**在线玩:https://xuanbin159.github.io/grand-token-auto/**(电脑上用 Chrome / Edge / Safari 打开;也可以下载 `dist/grand-token-auto.html` 双击玩)

老北京版 GTA 风格的单文件网页游戏(Three.js)。主角 Token 侠吃满 1M Token 就变身成变形金刚,拳打各路 AI 办公楼,最后干掉背刺自己的 Klaude。剧情致敬《蝙蝠侠:侠影之谜》和《圣安地列斯》,台词是京味儿评书腔。

> 纯属玩笑的恶搞游戏。里面的公司、产品和店铺都是谐音化名,只是剧情里的角色,与真实公司无关;主角是原创卡通形象。

## 玩法

| 按键 | 作用 |
| --- | --- |
| WASD | 移动(跟着镜头方向走);开车 W/S 油门刹车,A/D 转向 |
| 鼠标 | 拖动转视角;点一下画面锁定鼠标自由环视(锁定时左键拳、右键踢),Esc 松开 |
| J / K | 出拳 / 飞踢(打人会爆金币) |
| 空格 | 跳 / 砸地 / 开车手刹 |
| F | 上车下车 · 扫码骑共享单车 · 进站坐地铁 · 进店交互 |
| T | 变身(吃满 1M Token 后);变身后再按 T 变卡车 |
| L / R | 注意力光束 / 专精大招(5 级选专精后) |
| Q | 解除变身 |
| V / 滚轮 | 镜头:近景 · 中景 · 远景 · 经典俯视 |
| B | 北京生活面板:户口积分、驾照分、进京证、摇号、今日限行 |
| Tab | 角色面板:技能树、专精、地图、剧情 |
| Esc | 暂停(暂停菜单的大地图上点一下设导航点) |

手机:左下角摇杆(手指按哪儿摇杆就出在哪儿),右半屏拖动转视角,右下角拳 / 踢 / 跳,上车、进站、变身这些按钮到了能用的地方才出现;顶上一排是角色 / 北京 / 暂停 / 声音 / 镜头;画质在暂停菜单里切(自动 / 流畅 / 均衡 / 电影)。

- **真实北京地图**:OpenStreetMap 的二环一带真实路网、水系、公园和地标轮廓(二环内压缩到 1/4,二环外 1/6),街道、胡同都在真实位置,右下角实时显示所在街道和片区。
- **地标**:故宫(三大殿、午门、神武门、角楼、金水河)、天安门与端门、天安门广场、前门正阳门 + 箭楼、景山万春亭、北海白塔、钟鼓楼、天坛祈年殿 / 皇穹宇 / 圜丘、雍和宫、国家大剧院、北京站、德胜门、东南角楼、永定门;主角家 Token 王府 = 恭王府;二环上跑着上下文轻轨。
- **胡同与街道**:沿真实街道自动生成四合院、老字号铺面、酒吧街(后海 / 烟袋斜街 / 南锣鼓巷)、城外高楼和 CBD 天际线;红灯笼、胡同路牌、共享单车、70 个地铁站口。
- **交通**:车按车道走真实路网、路口转弯、看红绿灯排队;早晚高峰更堵;京牌 / 外地牌;警车沿路网追你。
- **北京特色**:尾号限行 + 电子眼 + 驾照扣分、外地牌要办进京证、户口积分落户、小客车摇号、地铁快速移动(过安检、按里程买票)、扫码骑共享单车、闯红灯、京城交通台;街上有广场舞、煎饼 / 糖葫芦摊、城管、遛鸟大爷、下象棋的、外卖小哥。
- **天气**:晴、雾霾、沙尘、雨(路面反光)、雪,会随机变。
- **3D 头像**:上传一张脸(默认是原创卡通主角),自动找脸和眼睛、生成 3D 头模(正面贴图片,侧面和后脑勺按肤色发色补齐),角色转身能看到侧脸和后脑勺;选头像时有 3D 转台预览和侧脸角度滑杆;帽子眼镜戴在 3D 头上。
- **画面**:第三人称跟随镜头(可切回经典俯视)、ACES 电影色调、跟随镜头的软阴影、雾气远景、天空与水面反光、夜景灯光;画质分低 / 中 / 高三档,手机自动降档。
- **GPS**:雷达随镜头旋转,沿真实路网给任务点和导航点规划路线。
- 12 个剧情任务(m0–m11,全部搬到真实地图:东二环 + 长安街赛车、胡同追逐……),15 处能进的建筑,装备上身,技能树 / 专精 / 升级。
- 打人爆金币、得云社听相声、王府大床存档。

## 换成你自己的脸

标题画面或暂停菜单里点「换主角头像」,选一张脸的图片:游戏会自动找脸和眼睛、生成 3D 头模,转台预览里能转着看;找得不准就拖动两个小圈对准眼睛,侧着拍的图片用「侧脸角度」滑杆调一下,点「用这张」。主角、机甲头盔、标题海报都会换成你的脸,帽子眼镜照样能戴。图片只存在你自己浏览器的本地存储里,不会上传到任何地方;点「恢复默认头像」就换回卡通主角。

## 改代码

```
game/            游戏源码(按文件名顺序拼进一个 IIFE)+ head.html(页面骨架与样式)
assets/          three.js r128、后处理(bloom / FXAA)、主角卡通头像、beijing_map.json(地图数据)
scripts/build.py 构建脚本 → dist/grand-token-auto.html
scripts/map/     OpenStreetMap → assets/beijing_map.json 的预处理脚本
scripts/dev/     无头 Chrome 冒烟测试 smoke.mjs、剧情全流程脚本 story_run.js
index.html       GitHub Pages 入口(跳转到 dist/)
```

改完 `game/` 里的文件后运行 `python3 scripts/build.py`,会重新生成 `dist/grand-token-auto.html`;装了 node 时顺带做语法检查。浏览器里的调试钩子挂在 `window.GTA`。
