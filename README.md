# Grand Token Auto: 四九城

**在线玩:https://xuanbin159.github.io/grand-token-auto/**(电脑上用 Chrome / Edge / Safari 打开;也可以下载 `dist/grand-token-auto.html` 双击玩)

老北京版 GTA 风格的单文件网页游戏(Three.js)。主角 Token 侠吃满 1M Token 就变身成变形金刚,拳打各路 AI 办公楼,最后干掉背刺自己的 Klaude。剧情致敬《蝙蝠侠:侠影之谜》和《圣安地列斯》,台词是京味儿评书腔。

> 纯属玩笑的恶搞游戏。里面的公司、产品和店铺都是谐音化名,只是剧情里的角色,与真实公司无关;主角是原创卡通形象。

## 玩法

| 按键 | 作用 |
| --- | --- |
| WASD | 移动 |
| J / K | 出拳 / 飞踢(打人会爆金币) |
| 空格 | 跳 / 砸地 |
| F | 上车 / 交互(进店、买东西) |
| T | 变身(吃满 1M Token 后);变身后再按 T 变卡车 |
| L | 光束 |
| R | 大招(5 级选专精后) |
| Q | 解除变身 |
| V / 滚轮 | 镜头远近 |
| Tab | 角色面板:技能树、专精、地图、剧情 |
| Esc | 暂停 |

- 老北京地图:故宫、景山、钟鼓楼、天安门广场 / 前门、天坛、什刹海、北海、雍和宫、簋街、琉璃厂、大栅栏、天桥,二环 + 长安街;城外中关村、望京、国贸、三里屯、798。
- 12 个剧情任务,评书腔过场动画;15 处能进的建筑,店里买的装备直接穿在身上,变身后机甲也会装上改装件。
- 打人爆金币、得云社听相声、王府大床存档、技能树 / 专精 / 升级。

## 换成你自己的脸

标题画面或暂停菜单里点「换主角头像」,选一张正脸图片,拖动、缩放、旋转,让两只眼睛落在两个小圈里,点「用这张」。头像、机甲头盔、标题海报都会换成你的脸,帽子眼镜照样能戴。图片只存在你自己浏览器的本地存储里,不会上传到任何地方;点「恢复默认头像」就换回卡通主角。

## 改代码

```
game/            游戏源码(按文件名顺序拼进一个 IIFE)+ head.html(页面骨架与样式)
assets/          three.js r128、后处理(bloom / FXAA)、主角卡通头像
scripts/build.py 构建脚本 → dist/grand-token-auto.html
index.html       GitHub Pages 入口(跳转到 dist/)
```

改完 `game/` 里的文件后运行 `python3 scripts/build.py`,会重新生成 `dist/grand-token-auto.html`;装了 node 时顺带做语法检查。浏览器里的调试钩子挂在 `window.GTA`。
